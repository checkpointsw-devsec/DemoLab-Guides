How the drawing was interpreted
  • Site gateways use .1 on each transit network and the ISP routers use .254, as labeled on the ISP clouds.
  • ISP2's interface names aren't labeled in the source, only eth0 .65 toward the Internet.
  • Only IPv6 prefixes are labeled. Host IPv6 addresses shown here follow the ::<host> pattern of the test host (1000:160:201::10) and are marked as inferred.
  • The dotted lines from Branch-Client and Branch-Linux to 172.40.1.0/24 are read as a second connection onto the Branch-2 LAN. Their addresses there aren't labeled.
  • The dashed 10.160.200.0/24 network links HQ-Client, Branch-Client and Branch-Linux. Host addresses on it aren't labeled.
  • Addressing between the ISPs and the Internet isn't labeled.
